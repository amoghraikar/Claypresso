# Loading State Component (`src/components/ui/LoadingState/`)

Renders a tactile clay spinner or skeleton placeholder during asynchronous data fetching and route transitions.

---

## Variants

- `spinner`: Clay-colored circular indicator with soft pulsating glow.
- `skeleton`: Shimmering placeholder blocks matching polaroid card and bento box dimensions.
- `fullscreen`: Centered overlay used during initial authentication verification.
