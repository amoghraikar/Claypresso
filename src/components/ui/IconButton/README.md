# Icon Button Component (`src/components/ui/IconButton/`)

A circular or rounded-pill icon trigger used for auxiliary actions such as wishlist toggling, closing dialogs, search triggers, and quantity steppers.

---

## Features

- **Clay Bevel**: Features `--shadow-clay-pill` with squishy press feedback.
- **Accessible Tooltips**: Mandates `aria-label` for screen reader navigation.
- **Micro-Hover**: Slight scale up on hover (`1.08`) and settle on press.
