# Empty State Component (`src/components/ui/EmptyState/`)

Renders a friendly, branded placeholder view when lists, carts, search results, or order histories have zero items.

---

## Features

- **Clay Icon Illustration**: Displays a charming clay illustration or icon.
- **Action CTA**: Direct link button guiding customers back to active collections or custom creations.
- **Customizable Messaging**: Configurable title, description, and secondary action link.
