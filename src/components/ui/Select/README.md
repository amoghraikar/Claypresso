# Select Component (`src/components/ui/Select/`)

Custom dropdown selector styled with Claypresso's curved clay borders and chevron indicators.

---

## Features

- **Stylized Dropdown**: Replaces native browser select with branded clay styling while preserving native accessibility on mobile.
- **Label & Error Handling**: Integrated with form validation schemas.
- **Custom Options**: Supports grouped options, disabled states, and placeholder prompts.
