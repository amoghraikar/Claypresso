# Container Component (`src/components/ui/Container/`)

The layout boundary component providing standardized horizontal padding and maximum layout widths across Claypresso.

---

## Configurations

- Max width: `1440px` (`var(--max-width)`).
- Desktop horizontal padding: `48px` (`var(--container-padding-desktop)`).
- Mobile horizontal padding: `20px` (`var(--container-padding-mobile)`).
- Centered automatically using `margin: 0 auto`.
