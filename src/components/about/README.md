# About Page Components (`src/components/about/`)

Client-side interactive components for the brand storytelling page (`/about`).

---

## Components

### 1. `AboutHeroVisual`
- Wraps the studio table photography in a restrained 6px parallax layer with subtle 3D perspective tilt.
- Anchors floating decorative clay talismans (stars, blobs) with proximity-based cursor repulsion (`ProximityElement`).

### 2. `AboutCustomBannerImage`
- Showcases the custom dragon couple keychain piece with smooth depth parallax and tilt response.
