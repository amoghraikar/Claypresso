# Shop & Catalog Components (`src/components/shop/`)

Components powering the catalog browsing experience on `/shop` and `/shop/[category]`.

---

## Components

### 1. `CatalogFilters.tsx`
- Filter controls by category, collection tag (`bestseller`, `new`), price brackets (`Under ₹250`, `Under ₹500`), and availability.
- Includes mobile filter bottom-sheet drawer with badge counters.

### 2. `CategoryBanners.tsx`
- Editorial header banners introducing specific categories with craft descriptions and piece counts.

### 3. `CatalogSort.tsx`
- Dropdown selector for sorting products by `Price: Low to High`, `Price: High to Low`, and `Newest First`.
