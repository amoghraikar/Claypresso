# Footer Component (`src/components/common/Footer/`)

The `Footer` component provides the terminal boundary of customer-facing pages, designed with editorial typography, studio craft guarantees, and catalog links.

---

## Features

- **Studio Brand Statement**: Bangalore studio origin story, small-batch craft philosophy, and postal seal.
- **Categorized Sitemap Links**: Grouped into "Shop", "Custom Atelier", "Customer Care", and "Studio Stories".
- **Domestic Shipping & Payment Badges**: Highlights UPI, Cards, India Post, and DTDC support.
- **Newsletter Subscription Input**: Stylized email capture field with claymorphic submit button.

---

## Files

- `Footer.tsx`: React component rendering the structured footer columns.
- `Footer.module.css`: CSS Module defining column grids, link hover states, and responsive stacking.
