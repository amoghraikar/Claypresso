# About Claypresso Page Route (`src/app/about/`)

Editorial brand storytelling page celebrating Claypresso's roots as an independent polymer clay studio in Bangalore, India.

---

## Sections

1. **Hero**: Headline "MADE BY HAND. MEANT TO BE YOURS." with the featured studio workspace photo wrapped in `AboutHeroVisual` (restrained parallax and reactive decorative shapes).
2. **What We Sculpt**: Gallery showcasing charms, keychains, mini phone straps, and bespoke portrait sculptures.
3. **The Handmade Process**: 4-step workflow explaining Color Conditioning, Tactile Sculpting, Slow Oven-Baking, and Glazing & Assembly.
4. **Custom Commissions Callout**: Explaining the bespoke creation philosophy with direct link to `/custom`.
5. **Small-Batch Standards**: Human touch guarantee, bubble-padded packaging, and domestic door-to-door courier tracking.
