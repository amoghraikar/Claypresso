# Studio Contact Route (`src/app/contact/`)

The direct communication channel for studio inquiries, custom order questions, and customer support.

---

## Features

- **Interactive Inquiry Form**: Captures customer name, email, order reference (optional), inquiry subject, and message.
- **Direct Studio Channels**: Displays studio email (`hello@claypresso.com`), Instagram handle, and studio location in Bangalore, India.
- **Hours & Expected Response**: States standard studio response times (within 24 hours on working days).
