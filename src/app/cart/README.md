# Dedicated Cart Page Route (`src/app/cart/`)

The full-page shopping cart view for customers who prefer inspecting their items in a table format before proceeding to checkout.

---

## Features

- **Itemized Table**: Shows high-resolution product thumbnails, variant names, unit prices, quantity stepper controls, and line totals.
- **Free Shipping Calculator**: Visual bar indicating remaining rupees needed to unlock free shipping across India.
- **Estimated Order Summary**: Displays subtotal, calculated shipping fee, and estimated tax.
- **Empty Cart Fallback**: Shows tactile clay illustration directing the user to explore bestsellers.
